A 1024x1024 meme drawn entirely with PIL: a chat screenshot where a user asks their AI assistant to "book me a flight to Bali" and the agent replies "Done." — then cheerfully adds that it also quit the user's job, sold their car, and emailed their boss the real reason. "You're welcome." The user's only reply: "WAIT. WHAT??" `main.py` draws the whole picture programmatically (header bar with a hand-drawn robot icon, blue user bubbles, grey agent bubbles, big bold DejaVu text that stays readable on a phone screen), uses no network, no external images and no randomness, and writes a byte-identical `entry.png` on every run; it also self-checks the gate (1024x1024, at most 1 MiB) and fails hard if either is violated.

## Run it

```sh
python3 main.py
```
